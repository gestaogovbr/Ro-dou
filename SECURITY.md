# Política de Segurança

## Versões com suporte

Apenas a versão mais recente do Ro-DOU recebe correções de segurança. Se
possível, atualize antes de reportar.

## Como reportar uma vulnerabilidade

**Não abra issue pública nem publique no Discord.** Envie o reporte em
privado para **ro-dou-suporte@gestao.gov.br**.

Inclua, se possível:

- versão do Ro-DOU e forma de instalação (Docker Compose ou Helm);
- descrição e impacto da vulnerabilidade;
- passos para reproduzir (ou prova de conceito);
- componente afetado (busca, notificação, DAGs de carga, chart Helm etc.).

Não envie credenciais, dados pessoais nem dados de produção.

## Divulgação

Pedimos que a falha seja divulgada publicamente somente depois que uma
correção estiver disponível.
